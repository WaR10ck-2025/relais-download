# Relais – Einrichtung herunterladen

Dies ist der Download-Bereich der **Relais**-App für Windows. Hier liegt nur das fertige Installationsprogramm — kein Quelltext.

## Herunterladen

**Neueste Version:** https://github.com/WaR10ck-2025/relais-download/releases/latest/download/Relais-Einrichtung.exe

**Prüfsumme (zum Vergleichen):** https://github.com/WaR10ck-2025/relais-download/releases/latest/download/Relais-Einrichtung.exe.sha256

## Du brauchst einen Einrichtungscode

Das Programm allein genügt nicht. Zum Einrichten brauchst du einen **Einrichtungscode**, den du vom Betreiber bekommst (einmal nutzbar, 48 Stunden gültig). Ohne gültigen Code richtet der Installer nichts ein.

## So geht's

1. `Relais-Einrichtung.exe` herunterladen und starten (mit Adminrechten). Weil das Programm nicht von Microsoft signiert ist, warnt Windows einmal: „Weitere Informationen" → „Trotzdem ausführen".
2. Auf der Seite **Einrichtungscode** den Code vom Betreiber einfügen.
3. Den Schritten folgen. Danach ist Relais eingerichtet, und die App hält sich selbst aktuell.

Fragen oder Probleme? Wende dich an den Betreiber.
